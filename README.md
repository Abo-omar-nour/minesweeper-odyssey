# 💣 Minesweeper Odyssey: Ultimate Edition (`v1.0.0`)

**كاسحة الألغام: أوديسا (الإصدار الأول المعتمد `v1.0.0`)** — لعبة كاسحة ألغام عربية متكاملة تجمع بين التصميم الكلاسيكي ثلاثي الأبعاد للخلايا، محرك حل منطقي بدون تخمين من الجيل الرابع (**V4 Pure-Local No-Guess Solver**)، ومسجل ألعاب تفاعلي كامل (**Gameplay Recorder & Replay Theater**)، مع أداء فائق السلاسة على الجوال والمتصفح.

---

## ✨ أبرز مميزات الإصدار الأول (`v1.0.0`)

1. **🧠 محرك بدون تخمين من الجيل الرابع (V4 Pure-Local No-Guess Engine)**
   - يضمن قابلية الحل المنطقي بنسبة **100%** على جميع الأحجام الـ 8 (من `8×8` حتى `36×26` بـ 250 لغماً) عبر خوارزمية **Iterative Subset Reduction** وتبديل الألغام الموضعي المزدوج (**Coupled Local CSP Mine Swapper**).
   - نظام تلميحات تعليمي ذكي يشرح السبب المنطقي للخطوة القادمة مع الإشارة إلى الخلية الأساسية والخلية المساعدة.

2. **🎬 مسجل الألعاب ومسرح الإعادة التفاعلي (Gameplay Recorder & Replay Theater)**
   - تسجيل تلقائي لكل جولة بدقة المللي ثانية مع حفظ البذرة (`Seed`) ومواقع الألغام وكافة الحركات.
   - 3 تبويبات ذكية: **الألعاب السابقة**، **أفضل الألعاب (الأرقام القياسية لكل حجم لوحة)**، و**المفضلة (Pinned)**.
   - شريط تحكم سينمائي يدعم **6 سرعات تشغيل (`0.25x`, `0.5x`, `1x`, `2x`, `4x`, `8x`)**، وتقديم/ترجيع خطوة بخطوة (`⏪` / `⏩`)، وشريط زمني تفاعلي (`Timeline Scrubber`).

3. **🎨 6 عوالم ثلاثية الأبعاد + نظام تقدم ومتجر متكامل**
   - 6 ثيمات بصرية ومؤثرات ثلاثية الأبعاد قابلة للفتح بالعملات (في نسخة الإنتاج `DEV_PREVIEW_UNLOCK_ALL = false`).
   - خريطة حملة من **50 مرحلة**، وتحدي يومي مشترك، ونظام أوسمة وإحصائيات مفصلة.

4. **📱 أداء 60fps فائق على الجوال والكمبيوتر**
   - دعم اللمس المتعدد للتقريب والتحريك (`Pinch-to-Zoom & Pan`) على اللوحات الكبيرة مع محاذاة دقيقة للمؤثرات البصرية (`getCellScreenCenter`).
   - خيارات تخصيص الرسوميات والـ 3D من الإعدادات لتناسب كافة الأجهزة.

## 🚀 طريقة الرفع على GitHub وإطلاق الإصدار `v1.0.0` (وتفعيل رابط اللعب المباشر للأصدقاء)

### 1️⃣ رفع الكود وإصدار وسم `v1.0.0`
افتح الطرفية (Terminal) داخل مجلد المشروع ونفّذ الأوامر التالية (أو شغّل ملف `publish_v1_release.sh` / `publish_v1_release.bat`):

```bash
git init
git add .
git commit -m "release: Minesweeper Odyssey v1.0.0 Official Release"
git branch -M main
git tag -a v1.0.0 -m "Minesweeper Odyssey v1.0.0 - First Official Release"
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main --tags
```

### 2️⃣ تفعيل رابط اللعب المباشر (GitHub Pages) لإرساله للمقربين
يحتوي المشروع على ملف إعداد تلقائي (`.github/workflows/deploy-pages.yml`) ينشر اللعبة مباشرة بمجرد رفعها:
1. ادخل إلى مستودعك على GitHub ثم افتح **Settings** -> **Pages**.
2. تحت قسم **Build and deployment (Source)** اختر **GitHub Actions**.
3. خلال أقل من دقيقة سيظهر لك رابط مباشر (`https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/`) يمكنك إرساله لأصدقائك على واتساب أو تيليجرام ليلعبوها فوراً على الجوال أو الكمبيوتر (ويمكنهم تثبيتها كتطبيق PWA من المتصفح عبر **إضافة إلى الشاشة الرئيسية**).

## 🛠️ التشغيل المحلي أو بناء تطبيق أندرويد (APK)

- **تشغيل الواجهة مباشرة:** افتح `frontend/index.html` أو شغّل `python backend/server.py` (يعمل على المنفذ `8080`).
- **بناء نسخة Android APK عبر Capacitor:**
  ```bash
  npm install
  npx cap add android
  npx cap sync
  npx cap open android
  ```
